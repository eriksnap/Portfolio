Rewired

A 3D experimental puzzle game built around the concept of control disruption. Each room the player completes changes their physical control layout. WASD might become inverted, rotated, or mouse driven, forcing them to constantly re-learn how to interact with the game world. The goal is to complete puzzles and progress through all rooms despite the shifting controls.

Portfolio XP System

A lightweight JavaScript XP and levelling system built for this portfolio site. Gaining XP updates a persistent display in the navbar. When XP reaches 100 the player levels up and XP resets, mimicking a basic game progression loop.

Rewired Control Scheme System

The core system powering Rewired. Built using a C# interface called IControlScheme with four concrete implementations: Standard, Inverted, Mouse Drive, and Rotated. A singleton manager swaps schemes between rooms, and trigger zones handle the transitions automatically.

C# Unity 6 Interface Pattern Singleton

The IControlScheme interface. Every control scheme implements the same three methods, so the rest of the game can read input without knowing which scheme is active.

WASDScheme, the standard control implementation of IControlScheme, showing how movement, jump, and crouch input are read for this scheme.
